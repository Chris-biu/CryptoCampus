# CryptoCampus 最终验收与演示指南

> 适用范围：桌面 Web 演示；移动端不在本次交付范围。本文只记录可复现步骤，不写入口令、私钥或验证码等秘密。

## 1. 一键启动

1. 确认 Docker Desktop 已启动。
2. 在仓库根目录准备本机 `.env` 与 `deploy/secrets/`。两者均被 Git 忽略，禁止提交。
3. 运行：

```powershell
docker compose --env-file .env up -d --build --wait
docker compose ps
Invoke-RestMethod http://127.0.0.1:8080/api/v1/system/status
```

4. 浏览器打开 `http://127.0.0.1:8080`。本机演示账号邮件地址保存在 `deploy/secrets/demo-accounts.json`，口令由部署人员从本机 `.env` 获取。

## 2. 首次演示环境初始化

初始化命令只允许在非生产环境、显式设置 `CRYPTOCAMPUS_ALLOW_DEMO_BOOTSTRAP=1` 时执行。它调用镜像内真实 openHiTLS bridge 生成平台 CA、用户证书、密信收件人、树洞签发者、计票台和口径章材料；不会启用 Mock。

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\scripts\bootstrap-demo.ps1
docker compose --env-file .env up -d --force-recreate --wait
```

运行后，秘密材料仅位于 `deploy/secrets/`，数据库位于 Docker 命名卷。生产环境会拒绝执行该初始化器。

## 3. 15 分钟小组演示顺序

### A. 身份与密钥环（2 分钟）

1. 切到“注册”，填写 `@campus.edu` 邮箱、验证码和强口令。
2. 注册后自动进入服务大厅。
3. 展示密码引擎在线、SM2 身份密钥指纹、平台 CA 签发证书与有效期。
4. 在用户中心点击“验证我的证书链”，确认平台 CA、有效期和吊销状态全部通过。
5. 说明口令、KEK 与私钥明文不会出现在页面、日志或数据库中。

### B. 密信快传（3 分钟）

1. 创建文字密信，设置可选提取口令和“阅后即焚”。
2. 分别复制分享链接与提取码。
3. 从公开提取页输入提取码，展示 SM4-GCM 解密、SM2 信封解封和发送者验签结果。
4. 再次提取，验证密文已销毁且仅保留 SM3 审计摘要。

### C. 匿名树洞（3 分钟）

1. 登录后点击“发布匿名树洞”。
2. 展示浏览器 WASM 本地生成 SN、两轮 SM2 盲签承诺、盲化、服务端签名和本地去盲。
3. 发布后确认帖子立即出现在列表，公开凭证校验通过。
4. 评论、点赞各自申领并消费独立凭证，重复 SN 会被服务端拒绝。

### D. 匿名投票（3 分钟）

1. 创建投票并选择班级或群组范围。
2. 参与者申领一张绑定 `vote_id + option_id` 的盲签选票并提交。
3. 展示一人一票、防重放、匿名计票。
4. 验证计票结果的 SM2 签名与计票台证书。

### E. 文件验真（2 分钟）

1. 上传真实 PDF、PNG 或 JPEG 文件（不接受 `.txt`），生成 SM3-with-SM2 `.ccseal` 侧车签章文件。
2. 上传原文件和侧车，展示摘要、签名、证书链、时间戳、吊销状态五步全绿。
3. 改动文件任意一字节后再次验证，摘要步骤必须明确失败。

### F. 管理、透视与测试证据（2 分钟）

1. 管理员查看引擎能力、用户列表、额度与治理入口；强调“治理权限不是解密权限”。
2. 运行 `N=10` 的经典国密真实性能基准，展示均值与 P99 并导出。
3. 打开密码透视，展示真实业务事件的脱敏流程记录。
4. 最后展示 GitLab MR、CI 全绿、KAT、覆盖率与浏览器验收截图。

本轮前端本地回归为 149/149，语句覆盖率 85.77%、分支覆盖率 82.78%；后端、集成、安全和桌面 E2E 仍应以对应流水线的新一次执行结果为准，不沿用旧计数冒充本轮验证。

抗量子能力不得在演示中宣称已通过：当前只完成经典国密真实基准；混合密信、Provider 重载和开销对比的验收状态见 [抗量子能力验收状态](../release/PQC-ACCEPTANCE-STATUS-2026-09-17.md)。

## 5. 失败判定

- 页面显示“成功”但服务端没有真实密码结果：失败。
- 动态库、CA、签发者或计票台材料缺失时自动回退 Mock：失败。
- 篡改 GCM Tag、文件摘要、签名或证书仍显示通过：失败。
- 学生能访问管理台，或管理员能查看密信明文、帖子归属、选票归属：失败。
- GitLab CI 任一必需作业红灯：不得合并。
